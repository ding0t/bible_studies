# Study Series

Each series takes studies already on this site in an order meant to be followed, one a week. Every
study stays where it is filed by subject, so the same study can belong to more than one series.

**For a group:** the leader reads the full study, which is the leader's notes, and the group works
from its printable group sheet, under the study's discussion questions. A week marked *coming* is
still being written.
